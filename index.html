~/projects/karpin-chat2024 · rebuilt after graduation

Karpin Chat

A chatbot that reads a large CSV file and answers questions about it in plain English.

How it works

You enter the path to a CSV file, the app loads and analyzes it, and you ask questions. A simple question gets a direct answer. A larger result comes back as a CSV file.

Under the hood

An LLM (Llama 3 through Groq) turns each question into SQL. The backend validates the query and runs it read-only, so generated SQL cannot change the data. Built for large datasets, with CSVs of millions of rows as the target.

Where it came from

It began as a hackathon project in the 20-day ACM Summer School on Generative AI for Text at IIT Gandhinagar (2024), when I knew little about LLMs. After graduating I rebuilt it properly with AI assistance.

~/projects/fake-profile-detection2023 · first project with real-world exposure

Fake Social Media Profile Detection

Type in an Instagram ID and get a verdict on whether the account is genuine or fake, with a percentage.

How it works

The app collects public profile details: followers, following, bio, external URL, activity, join date and profile picture. The data goes through three trained models, KNN, SVM and Random Forest, which each return a decision and how likely the account is to be original or fake.

Training

I trained the models on a Kaggle dataset of about 2 million accounts, reformatted to my chosen features. The metrics are in the Google Colab notebook.

Choices I made

I researched both Twitter and Instagram. Twitter would have needed NLP skills I did not have yet, so I went with Instagram. The first version used Python, Flask and minimal CSS, and I later rebuilt it as a full-stack app with Java, React, REST APIs and a database.

~/projects/employee-management2025 · Cognizant internship

Employee Management System

A web app used by both managers and employees, with the login separating the two. Employees clock in, see their holidays and shift timings, and apply for leave. A rejected request can be followed up with a direct email to the manager. Clocking in more than an hour after the shift starts marks the employee absent. Managers clock in, review leave requests and set shift schedules. Each profile shows designation, leaves, performance and clock-in history.
